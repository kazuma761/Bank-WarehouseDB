Data sources

Plug in your own data, then ask questions about it. BankQL only ever reads it.

Import files

CSV, TSV or Parquet. Each file becomes one table in a new local DuckDB database. Importing a file with the same name again replaces that table. Save Excel sheets as CSV first.

Connect a database

A SQLAlchemy URL, e.g. postgresql+psycopg://reader:pass@host:5432/db or sqlite:////path/file.sqlite. Use a read-only database user: a user that can write is refused. The URL is stored only in .env.
